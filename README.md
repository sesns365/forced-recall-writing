# 「字」從心生：強制回憶寫字

依陳淑麗、陳思涵、曾世杰（2023）〈強制回憶寫字教學法對國小三年級寫字困難學生之介入成效〉（特殊教育研究學刊，48(3)，67–97）設計的上課網站。六節課、每節 4 個字（南一五上）。

學生網址：https://sesns365.github.io/forced-recall-writing/ （只有練習）
老師網址：https://sesns365.github.io/forced-recall-writing/#/t （上課簡報、測驗、批改與匯出）

## 上課流程

1. **上課簡報（老師投影）**：老師首頁選「第 N 節 → 上課簡報」。情境圖與短句 → 圈出今天的字 → 每個字：語詞與意思 → 字卡 → 每日一字動畫 → 部件與口訣 → QR code 進入練習。鍵盤 ← → 或簡報筆翻頁。
2. **學生練習（平板）**：掃 QR code 或學生首頁選「開始練習」，先輸入代號。五大步驟：讀 → 拆（看筆順、拆部件、組部件、練習寫 3 次：至少完成 1 次跟著筆順寫，進入後不能回到前面步驟）→ 看 → 蓋（一定要寫滿 4 遍，只顯示遍數不顯示字跡）→ 對（每一遍都自我檢核後才能進入下一字；可訂正）。
3. **隨堂測驗**：4 個字練完直接進入。畫面鎖定，不能回去看字；預設「老師唸題」。老師按住右下角 3 秒才能中途結束。
4. **保留／追蹤測驗**：老師首頁「保留／追蹤測驗」，依教學日程選組別。
5. **批改與匯出**（老師首頁）：批改（○ △ × 空白）、匯出這台裝置的紀錄（ZIP：CSV＋字跡）、匯入合併多台裝置的匯出。

紀錄只存在各自的裝置（不上傳、不存姓名），請定期在老師頁匯出。

## 維護

- 教材內容（字、語詞、意思、口訣、部件、易錯點、影片、日期）：`tools/action_plan.py`
- 情境圖：`resources/scenes/1.jpg`～`6.jpg`（16:9）
- 修改後執行 `python3 tools/site.py`（重新產生 `public/` 的資料、24 字筆順、裁切字型與情境圖），再提交。推送到 `main` 後 GitHub Actions 會自動建置發布。
- 離線教材包與紙本測驗單：`npm run build:pack`（輸出到 `dist-pack/`）。
